# Vantage guide

## Start here

Vantage is an Ashita v4 addon. Load it with `/addon load vantage`. The [install notes](INSTALL.md) show how to copy it into your game folder. Vantage draws its own displays and leaves the game's own windows as they are.

Type `/vantage` or `/vg` to open the main page. The self-buff, self-debuff, and target timer panels start enabled. Party members' timers, Watched enemy timers, the recast panels and the buffs beside the game's party list are optional. Party members' timers and Watched enemy timers start as bars, which name whose effect each row is. Timer panels normally hide when they're empty. Show samples fills every panel with effects that are clearly made up, so you can arrange them. Samples never count as something Vantage saw in the game, and they never set off alerts. A sample icon panel wears a small SAMPLE tag. While the settings window is open, samples draw over it, so it never hides them. Clicks still go to the settings. The sample under the mouse, its tag included, steps back behind the window for as long as the mouse is on it. That way you can see the settings under it and its tooltip. A sample under one of the window's tooltips or open lists steps back too. In edit mode every display draws as usual, under its outline.

The window always opens on the main page, and you set most things there. The main page goes in the order you set things up: **What to show**, **How it looks** and **Moving**. Every change on it is one Undo step. **Edit** beside a display opens that display's own page. **Profiles**, **Timer durations** and **Help** sit beside the search box at the top.

A line shows at the top only while something needs a hand. It shows when timer panels are paused (**Resume**), when the Hidden everywhere list is paused (**Use it again**), when Party cooldowns has nowhere to show (**Show them in a list**), when the ready pulse has no recast panel to play on (**Use a spot of its own**), when edit mode is on (**End edit mode**), or when `/vg hide` has hidden the displays (**Show**).

1. **What to show.** **Starter profile** at the top sets all of this for a role at once (see [Starter profiles](#starter-profiles)). Or tick what you want: the timer panels, **Recasts** (**Spells**, **Abilities** and **Items**), **Ready pulse**, **Party list buffs**, **Overhead icons**, **Party cooldowns**, **Phantom Roll**, **Pet** and **Alerts**. Each has its tick and **Edit** on one row. The rows go in two columns when the window is wide enough. **Overhead icons** draws buffs and debuffs above heads in the game world. **Party cooldowns** shows the list of two-hours and key abilities Vantage saw your party use. It also turns on the party cooldown watch, which starts off. **Phantom Roll** shows a roll while you or a party member rolls. **Pet** shows your pet while you have one. A display stays empty when there is no matching information to show. **Alerts** has **Unmute** while alerts are muted. The **Hidden everywhere** line names what your hide rules hide and counts the rest, and its **Edit** opens the list. The last ticks are **Hide Vantage in cutscenes, on the map and when the game hides its menus**, **Hide timer panels while I type** and **Show details when I point at a timer**. Party list buffs and Overhead icons hide then either way, because they sit on what the game hides.
2. **How it looks.** Pick a **Skin**. It applies at once to every display and this window, with its fonts and artwork. It keeps your sizes, positions, filters, locks, the colors you set for one effect and row text colors. When a pick would replace a display's own look, the page names those displays first and waits for **Apply** or **Cancel**. **Font** sets the font for every display and this window. If this window can't use that font, it keeps its plain one, and a line under **Font** says so. **Text size** is the size of effect names and countdowns. **Icons** panels go by **Icon size**, and a line says so while your timer panels are all on Icons. **Size** has **1x**, **1.5x** and **2x** buttons and a slider. A button sets the size. In the same Undo step, it also re-spaces the timer panels, alert notices and the Pet and Phantom Roll displays that are still where they started, so they fit the new size clear of the game's windows and chat log. Every display you moved keeps its position. Layouts, fields and colors never reset. The slider only sets the size.
3. **More look**, under How it looks, starts closed. It holds the artwork. That's **Icons** and **Recast icons**, and on Original FFXI and XI View it's also **Gauges** and all eight client window types under **Window frame**. It also holds **Icon size**, **Row height**, **Space between rows**, **Heading size**, **Opacity**, **Corner rounding**, **Background**, **Border** and **No boxes or headings**, which takes **Background** and **Border** away. While your timer panels are all on Icons, a line says which of these reach them. Then come the text effects for every display (see [Countdown text](#countdown-text) and [Expiring effect icons](#expiring-effect-icons)). It ends with **Color each countdown by how sure Vantage is of its time**, **Settings text size** and **Colors**, which has the shared colors and **Back to the skin's colors**.
4. **Moving.** A line says which displays are unlocked. One button sets every display's lock. It reads **Unlock all**. Once a display that is on is unlocked, it reads **Lock all**. The button covers the status and recast panels, the party list buffs, visual alerts, the party cooldown list, the ready pulse spot and the Phantom Roll and pet displays. Each action supports Undo. Hold Shift until handles appear. Then drag the center to move a display, or drag an edge or corner to resize and wrap it. Individual locks stay above the scrolling settings when there is room. In short menus, scroll the page to reach these controls. Locked displays stay fixed even while you hold Shift. With the pointer on one, a note says where to unlock it. Every display starts locked. **Edit mode** outlines every display so you can pick and move it (see Edit mode below). **Show samples** puts samples on every display that is on. It doesn't turn anything on. The button then reads **End samples**, which ends them all. **Hold Shift to see through this window** hides this window while you hold Shift, so you can place displays under it. **Grid mode** starts off. It makes the displays you tick for it snap as you drag them. While it's on, **Grid and snapping** under it holds the ticks, the grid and the snapping switches.

A look you set for one display stays until you change it. Vantage doesn't reapply anything on its own.

The timer and recast panels, Party list buffs, Overhead icons, Party cooldowns, Phantom Roll, Pet and Alerts open from **Edit** on their main page rows. Hidden everywhere opens from its line there. **Profiles**, **Timer durations** and **Help** at the top open **Profiles and sharing**, **Timer durations** and **Help**. Each of those pages has **< Back**, which goes back to the main page, and its name at the top. The header keeps **Undo**, **Redo**, the search box and those three on every page. The X on the title bar or Esc closes the window. When you change pages, the new page starts at the top. Search jumps to its match. The window always opens on the main page. **Hidden everywhere** hides an effect on the timer panels, Party list buffs, Overhead icons and Pet. Each panel has a **Filters** tab for its own rules and ordering. Search also finds controls on editor tabs that aren't open. If a control shows only while something else is on, search finds that switch instead. A word ending in s finds the word without it too, so `targets` finds **Target timers**. A result with nothing to light up on its page opens the page and clears the search. **Previous match**, **Next match** and the count of matches show only while the page has a match.

**Edit** beside a timer or recast panel, Party list buffs, Overhead icons, Party cooldowns, Phantom Roll, Pet or Alerts on the main page opens its editor. Its top line has **< Back**, which goes back to the main page, the panel's name, **On**, **Show samples** and **Locked**. Overhead icons have no **Locked**, because you don't drag anything over a head. Alerts have no **Show samples**, because an alert has no sample to show. **On** changes only that panel. Hiding Target keeps Self buffs and Self debuffs visible, even when you target yourself. While every status and recast panel is paused, a line at the top of the main page says so. Each panel keeps its visibility choice. Turning on an individual panel, or clicking **Resume** on the main page, resumes the shared display switch. **Show samples** shows samples on every timer and recast panel that is on. It doesn't turn anything on. On Party list buffs, Overhead icons, Party cooldowns, Phantom Roll and Pet, it shows that display's own samples. While the display is off, it says to turn the display on first. Unticking **On** ends them.

Under that line are the tabs. **Show** is for what it lists and what each row shows. **Size and place** is for how big it is, where it sits and what it moves with. **Look** is for its heading, box, bars, colors and row text. **Filters** is for what it hides, pins, orders and renames. There's also **When to show**. Vantage draws only the open tab, and search looks through them all. A display has no tab it has nothing for. Each panel remembers the tab you left it on. **Reset this display** sits at the foot of every tab. It puts that panel back as it started, and it asks first. While a panel is locked, what would move or resize it is grey, and a line says **Unlock it to move or resize it.** Fitting a panel to what it shows, and Fills, stay yours to change. Browsing these tabs doesn't write settings or use Undo.

If a settings page runs into an error, the window closes until you open it again. Vantage puts back the change the page was making and reports the error in chat. `/vg` then says the window closed after an error and that `/vg` opens it again. While your visibility options hide the panels (an event, the map or a hidden interface), `/vg` says the window shows when they end. The window follows those options together with the panels.

### Starter profiles

**Starter profile** is at the top of **What to show** on the main page. It turns on the displays a role wants and turns the rest off. The list opens on the one that suits your main job. It reads `(in use)` beside the one your settings match. Picking one changes nothing until you press **Apply**.

- **Apply** does it in one Undo step. It also puts samples on every display that's on, so you can see what you got. **End samples**, under **Moving**, takes them off.
- To keep one as a profile, **Apply** it, then click **Save as new** on **Profiles and sharing**. To load it on WHM, pick it there, pick WHM under **Load this profile when I change to** and click **Link**. A saved profile holds its whole look, so a look you change later doesn't reach it until you overwrite it.
- `/vg starter healer` applies one from the chat line, with no samples.

All six turn on Self buffs, Self debuffs, Spell recasts, Ability recasts, the Pet display and overhead icons, in the recast layout you chose. The recast panels and the Pet display stay hidden while they have nothing to show.

A starter keeps your skin, fonts, colors, sizes, positions, locks, hide rules, your own alert rules, the party list **Countdowns**, job links, saved profiles, item recasts, and the overhead **Other players**, **Other players' pets** and **You** ticks. The parts of the Pet display and the lights on overhead icons stay as they are too, once Pet or Healer has turned them on.

Starters add alert rules and never take one away. They skip a rule you already have for that effect and event, whether it's on or off, and whatever it's called or covers. A starter with rules of its own turns **Alerts** on. **Silenced** tells you when you're silenced. **Sleep ending** warns 10 seconds before Sleep, Sleep II or Lullaby runs out on anything.

The lights go by your job and level, as [Mob buffs you can remove](#mob-buffs-you-can-remove) and [Debuffs you can remove](#debuffs-you-can-remove) say. The debuff lights need White Mage as your main or support job. The dispel lights need a job that can dispel. Most effect times on a pet are estimates.

### Hide selected buffs and debuffs

Click **Edit** on the main page's **Hidden everywhere** line, or type `/vg filters`. **Edit the list** on a display's **Filters** tab opens it too. **< Back** goes back to the main page. Vantage hides what's on this list across the timer panels and the buffs beside the game's party list. Overhead icons and Pet use it too, and each can stop using it on its own **Filters** tab. The list doesn't touch recasts. It starts empty. While the list is paused, each page that uses it says so, with **Use it again**.

Type part of a name in **Find an effect**, pick it under **Effect**, and click **Hide it everywhere**. Each effect on the list shows by name under **Hidden everywhere**. **Remove** takes one off. Hiding Level Sync removes its buff icon. Hiding Copy Image hides it no matter how many shadows are left.

**Hide only for some players or jobs** starts closed. It narrows a rule. **Add a rule** adds one that's turned off. It goes on the effect chosen above, or on **Any effect** when none is chosen. Set it up, then tick **Use this rule**. **Rule** picks which you're changing. A rule that's off, or on **Any effect**, shows only here. Choose an effect or **Any effect**, **Buffs or debuffs**, and any mix of these:

- **Player name:** Type an exact name. Case and spaces around it don't matter. Leave it blank for anyone. This is the player with the effect, not its caster.
- **Main job:** Pick a main job or **Any main job**. If the client doesn't give a member's job, such as for a distant or out-of-zone member, that member doesn't match a job-specific rule.
- **Who:** Pick everyone, only you, your party including you, both other alliance parties, or Alliance 1 / Alliance 2 individually. You can also pick Enemies, Other players (outside your party and alliance) or Pets. Those match wherever they show, on overhead icons too. Enemies and Pets have no player's name or job. Picking one clears those, and their two rows go away.

Every condition in one rule must match. Any enabled rule that matches hides the effect. That includes effects that local display filters pin or include. For example, Signet + WAR + My party hides Signet only on WARs in your party. Any effect + Debuffs + a player name hides that player's debuff icons and timers. Tracking and alerts continue normally. Effects with no known duration still appear unless a rule hides them.

**Pause this list** shows everything on it again without deleting anything. The main page then says it's paused. **Use it again**, there or here, puts it back. **Clear the list** takes every effect and rule off it. Undo restores changes. Full profiles and shared presentation include these rules. Placement-only sharing and skins keep them unchanged.

Vantage keeps its settings in `config/addons/vantage`. This guide calls that location the **settings folder**. Each character has a separate settings file. Vantage stores profiles and optional shared placement beside those character folders. Custom fonts, sounds, caches, and reports use this same location. Replacing the addon folder leaves these files alone.

## Read a timer

- **Server:** The game sent a current timer for a status on you. The number is the time left. The original total and the elapsed time appear only when Vantage saw the effect being applied. So if you load Vantage midway through a buff, it doesn't make up the buff's original duration.
- **Estimated:** Vantage saw the effect being applied and has a supported duration model for it. These rows use estimate styling, and their details point out the uncertainty. Caster equipment, random durations, resistance, or later server adjustments may change the actual duration.
- **No countdown:** The effect is present or Vantage saw it, but Vantage has no usable current duration for it. It shows its icon, or a bar with a plain track, in its normal look. That doesn't mean the effect is permanent. An estimate that ran out with no wear-off message stays like that until it leaves.

Hover a row for its evidence, caster when known, effect ID, and available timing details. Duplicate icons stay separate. When a timer reaches zero, Vantage doesn't remove the row or fire a removal alert. That needs evidence from a current status snapshot or a removal Vantage sees. Old observations that were never confirmed go away quietly.

Rows follow Phoenix's own rules for repeated effects. Recasting a buff you already have refreshes its row. When the server lists the old and the new copy together for a moment, the old copy leaves quietly and nothing is removed or gained. A song of the same kind and tier refreshes its copy in place rather than adding one. For example, an Etude refreshes an Etude of the same tier, and a Minuet refreshes the same Minuet. When a bard sings past their song limit, the song of theirs that ends first is the one that drops. When you die, your rows stay until the server clears them. Vantage credits Weakness to whoever raised you.

Self snapshots cover the status slots the client exposes. Party snapshots cover members of your own party in the same zone, when their icon update is available. They don't give exact timers. Other players, alliance members, pets, and enemies can appear through what Vantage sees, but Vantage has no complete, guaranteed list of their effects. Changing targets doesn't find effects that were applied out of sight.

### Hits on a mob

A mob's Sleep, Sleep II and Lullaby leave at the first hit Vantage sees on it for more than 0 damage, the same way Phoenix takes them off. The hits that count are melee, ranged and weapon skill hits, Barrage and Sange shots, damaging spells and abilities, drains, blood pacts, added effects and skillchains. Phoenix lands every player sleep and lullaby as Sleep, so they all behave alike. A miss, a hit for 0 and a resist change nothing. The removal counts for **Effect removed / wore off** alerts.

Bind stays after a hit but loses its countdown. Phoenix breaks it at 95 hits in 100, so there's no way to know its time. If it breaks, its caster gets the wear-off. A counter on a bound mob's attack is a hit on it too. Spikes don't count. Phoenix deals their damage without waking a mob or breaking Bind.

Damage ticks from Poison, Dia, Bio and the like wake a sleeper too. But the game sends no message for a tick, so only the sleep's caster sees it leave, through its wear-off. Sleepga from Shiva and Nightmare from Diabolos send no wear-off to anyone, so a hit is the only sign. Effects on you and your party follow their own listings. Vantage counts these hits only on mobs and your pet.

### Shadows and Third Eye

The game lists buffs for your own party only. So on a mob or an alliance member, Vantage follows Copy Image and Third Eye itself, from what it sees.

Copy Image is one effect, whatever its icon shows. So a filter or an alert on it holds no matter how many shadows are left. On a mob or an alliance member, Vantage counts the shadows, starting from the spell. Ichi gives 3, Ni 4 and San 5. But Ni gives one less to Ark Angel HM and Shikaree X, and to an alliance member whose main job isn't Ninja. When the game hasn't sent their job, Vantage counts them as a Ninja. If that leaves a shadow too many, it goes at the next hit that gets through. Vantage takes one off for each shadow it sees soak up a hit, a spell or a counter. The icon goes with the last one. A hit for damage that gets through means none were left, so the icon goes then too. A weapon skill with Sneak Attack or Trick Attack can use up shadows without the game saying how many. Some attacks take every shadow at once without a word. So the count can read high until the next hit.

Third Eye counts down its 30 seconds, and Seigan its 5 minutes. On a mob or an alliance member, Third Eye goes when Vantage sees it anticipate an attack, sees a swing land on them, or sees them cast Utsusemi. With Seigan up, it can stay after an attack it anticipates, and the game doesn't say when it does. So its icon stays until its time is up or a swing lands. Some area attacks from mobs take Third Eye off without a word. When that happens, its icon stays until its time is up.

## Panels

Open a panel with **Edit** on the main page. Each panel has its own position, width, maximum height, visible row limit, layout, order, bar direction and filters. Self buffs, Self debuffs and Target timers start as horizontal icon rows. Party members' timers, Watched enemy timers and the recast panels start as bars.

**Bars** keep rows short. **Expanded bars** make room for more on each row. **Text** shows each name and its countdown, with no icon or bar. **Icons** shows just the icon and its known countdown, with no background, heading, name or gauge. Effects with no countdown and Level Sync show only their icon. Countdown bold, shadow, outline, fonts and client artwork still apply. Bar field choices stay saved when you switch back. Countdowns start as centered text directly below the icon, at half the icon's rendered size. Their own size, position and gap are under **Countdowns on icons** on the **Size and place** tab.

**Fills**, on the same tab, picks which way a panel fills in every layout. The choices are **To the right, then down**, **To the left, then down**, **Down, then to the right** and **Down, then to the left**. The panel's width and height decide when its contents wrap. Names, timers and bar fill stay readable in their normal direction. **Bar width** sets the preferred width of bars when several fit beside each other. Icons keep the size you picked.

For bars, **Each row shows** picks what a row holds: **Icon**, **Name**, **Who it is on**, **Countdown**, **Who cast it**, **Time elapsed** and **Full length**. Vantage leaves out a part with no value, such as a caster with no name or a total that was never seen. When the full duration was never seen, the hover says what time the bar spans.

**Box**, under **Show its heading** on a panel's **Look** tab, picks the box drawn around that bar, expanded or text panel. **Shared** is the default, and it follows **Background** and **Border** under **More look** on the main page. **Background and border**, **Background only** and **Border only** draw just those parts, in the Original FFXI window art or the skin's colors. **None** draws no backdrop or border. The heading still follows **Show its heading**. While **No boxes or headings** is on, no panel draws a box. The pick goes away and a line says why. **Icons** panels never draw a box, so they have no pick. A skin, a **Size** button and **Put every display back where it started** keep each panel's pick. **Reset this display** puts it back to Shared. Profiles save it.

Unlock a panel with `/vg unlock` or **Unlock all** on the main page. Hold Shift until the eight handles appear, then left-drag its middle to move it. Drag any edge to resize one dimension, or any corner to resize both. It goes exactly where you drag it. While **Grid mode** is on, a panel ticked for it snaps instead. A move snaps to the grid, the screen's center and edges, the other displays, the game's party list and the chat log. A resize snaps the edge you pull. Both work the way **Grid and snapping** on the main page sets them (see Edit mode below). The line it snapped to shows while you drag, and so does the grid while **Show the grid** is on. Both go away when you let go. Locked panels stay fixed. You can't place a panel while chat is open or the game isn't the active window. Alt-Tab stops an active drag or resize. Holding Shift in another app doesn't make Vantage clickable. While you hold Shift, unlocked displays show a temporary name label. That includes Self buffs, Self debuffs and Target timers. A label sits above its display. When another display is in the way, the label sits below its display or inside its top edge. Labels also identify recasts, the party list buffs and alert notices, even when normal headings or backgrounds are hidden. Release Shift to hide them. Each label also shows the live **width x height in pixels**, such as **320 x 80 px**. The numbers update as you resize. They stay visible while you hold Shift, so you can match another display. They measure the outlined area at its actual screen scale. The labels don't catch clicks or change the display's size. A panel's **Across**, **Down** and sizes on **Size and place** are the same numbers in settings. They're grey while the panel is locked. Past the screen's edge, they show where the display really is, and what you typed stays for a bigger screen. Resize handles have larger grab areas and highlight the edge you're changing. Close the settings window if it covers the display you want to arrange. Locked displays and an open game chat input prevent resizing.

You can hold Shift and drag inside the settings window to move it, or drag an edge or corner to resize it. Its normal title and resize handles work too. **Hold Shift to see through this window** starts on. While it's on, drag the title to move the editor, or drag its edges to resize it. The inside of the window lets you reach the displays below. It stays see-through for the whole of a drag there, across the title and edges too. Release the mouse to save. Undo and Redo restore position and size. Vantage's windows never dock. Resizing a timer in either direction turns on text wrapping. Visual alert notices support the same Shift gestures. Their height fits their content at first. A vertical resize sets a fixed height. On the **Size and place** tab of Alerts, set **Tallest** to **Fit** to restore automatic height, or turn on **Locked** to keep notices fixed. `/vg lock` and `/vg unlock` include notice placement.

These gestures cover all five status panels, separate and combined recasts, the party list buffs and their panels of their own, visual notices, and the settings window. Contents wrap within the font and icon sizes you picked. A group beside the game's party list only moves, and you can move it from its edges too. A group in a panel of its own also resizes. Vantage doesn't resize the original game windows.

**Bar shape** on **Look** picks a **Full bar** or a **Thin rail**. Turning off **Show the bar** leaves just the text. Thin rails use the Original FFXI and XI View gauge artwork. Full-fill rows use a subdued flat fill so the texture doesn't wash out the text. You can also hide the text and keep the bars with **Show row text**. **Fill from** picks the side the bar starts from. **Bar runs** picks whether it empties or fills. Row height, bar thickness, shaded bars, ending-soon colors and marks, and the panel's own colors are on its **Size and place** and **Look** tabs. **Shaded bars** fades the fill along the bar, to **Bar fill end** or else to a darker shade. A bar in the ending-soon color or an effect's own color stays one color. A row shows while it changes something. With **Show the bar** off, the bar's rows go. With **Show row text** off, the row text rows go. **No boxes or headings** takes away the heading and box rows and says so. A tab with nothing to change goes the same way, such as Pet's **Look** with **Show HP, MP and TP** off. Search takes you to the row that brings them back. On **Icons**, and on a row with no bar, the countdown takes the ending-soon color over any color of its own. Countdown text works like every countdown in Vantage. It shows the available time without an added symbol, in whole hours (**2h**), then whole minutes below an hour (**5m**), then seconds below a minute (**30s**). Effects with no known duration leave the countdown blank. Source and estimate details stay in tooltips, and estimated bars keep their separate styling.

The **Row text** fold on **Look** sets the order, labels, dividers, line breaks, colors and alignment of a row's parts. **Up**, **Down**, **Between parts** and **Divider before it** show once two parts share a line. **Label position** shows once a part that's shown has a label. While **Wrap long rows** is off, **When space is short, keep the higher-priority parts** keeps the parts you choose when space is tight. You can still hover a row for its details. Timer formatting never makes up a duration.

**Fit the width to what it shows** fits content between **Narrowest** and **Widest**, and rows past **Most shown** don't count. With **Same width as the chat log** on, a panel beside the chat log goes by the chat log's width, and these rows go away. **Moves with**, on the **Size and place** tab, ties a panel to another display or to the chat log. The panel follows along even while locked. On **A spot on the screen**, the spot and its distances say where the panel goes, so **Across** and **Down** go away. If you drag a panel that moves with something, it stops moving with it. Following the chat log needs the game's chat window to be readable. While it isn't, the panel sits at its **Across** and **Down** and doesn't guess. A horizontal resize turns off **Fit the width to what it shows**. A vertical resize turns off **Fit the height to what it shows** and sets a fixed height. Tick either one on the **Size and place** tab to restore fitting. The other dimension keeps its setting. A bars panel with a fixed height keeps that height however many rows it has. Its smallest height holds a heading and one row. When the room or a row limit cuts effects, a panel shows the ones that fit and nothing after them. The count on its heading is the number of rows it shows.

**Members**, on the **Show** tab of Party members' timers, shows only the members of your party you tick. Leave everyone unticked to show every member. Watched enemy timers keeps what Vantage saw on an enemy after you change targets. To watch an enemy, use **Watch my target** on the panel's **Show** tab, or `/vg watch` with an enemy selected. **Watching** lists who you watch. The list clears when you zone or change characters, because a later spawn can reuse an ID. Named profiles don't carry it. While nobody is watched, the tab says so.

**Also list enemies I debuff**, on the **Show** tab of Watched enemy timers, also lists every enemy with a debuff you cast. It lists each one for as long as the debuff lasts, without watching it. Alert rules for Watched enemy timers go by the same list, apart from **Required effect missing** rules. Those go by the enemies you watch. The setting starts off, and Profiles and shared presentation carry it.

Hiding a panel or excluding an effect doesn't turn off tracking or its alert rules. `/vg hide` hides Vantage's displays for this session, until you type `/vg show`. Ashita's `/hideui` does the same while it's on. Alert notices still show, so you don't miss a warning. Use `/vg mute`, or **On** on the Alerts panel, to change alert behavior.

### Mob buffs you can remove

Target timers and Watched enemy timers can light a mob's buff when your job and level can take it off now. They use the same checks as the overhead icons, and you need one of these. Dispel needs RDM 32, or /RDM with a main job of 64 and up. Magic Finale needs BRD 33, or /BRD at 66 and up. Both have to be learned. Blank Gaze needs BLU 38, learned and set. Dark Shot needs COR 40, with a Dark Card or Trump Card in your inventory, a Marksmanship weapon (gun or crossbow) and its ammo. Level Sync counts. A lit icon gets a bright border in **Light color**, with a glow behind it while **Glow around lit icons** is on. A bar row with no icon gets the border around its bar. The switch, **Light up buffs you can remove**, starts off. You'll find it on each panel's **Show** tab. Once it's on, **Glow around lit icons** and **Light color** show on its **Look** tab. The glow starts on. A mob's debuffs and players' buffs never light here. Profiles and shared presentation carry each panel's choices.

### Debuffs you can remove

Self debuffs and Party members' timers can light a debuff the same way. On Phoenix that takes White Mage as your main or support job, at the spell's level, with the spell learned. The spells and their levels are Poisona (6), Paralyna (9), Blindna (14), Silena (19), Cursna (29), Erase (32), Viruna (34) and Stona (39). Stona's level is past what a /WHM reaches. Level Sync counts. **Light up debuffs you can remove** starts off on both panels. It's on the same **Show** tab, with its own **Glow around lit icons** and **Light color** on **Look**.

A lit icon means you can try. Cursna only has a chance on Doom, and Erase takes off one debuff at random. So a lit debuff can stay on after the cast. Only your job, level and learned spells count. Items and abilities that remove debuffs light nothing, and a Silenced White Mage still sees the light.

## Party list buffs

Vantage can show buffs and debuffs beside the game's own party list. It shows a row of icons for each member of your party and of the other two alliance parties. The game's party and alliance windows stay as they are. Vantage reads where their member rows are and draws beside them. Open the panel with **Edit** on the main page's **Party list buffs** row, or type `/vg party` or `/vg party config`. It has the same top line and tabs as a timer panel.

**On** turns the buffs on or off together, and so do `/vg party show` and `/vg party hide`. If you turn them on with every group off, Your party turns on. The **Show** tab starts with a tick for **Your party**, **Alliance 1** and **Alliance 2**. After those, you pick **Buffs and debuffs**, **Buffs only**, **Debuffs only** or **None**. An effect that is neither a buff nor a debuff, such as Level Sync, shows only with **Buffs and debuffs**. **None** shows no effects. It's for when you only want Party cooldowns beside the party list. The settings that only shape effects leave the page until you pick another one. Each change is one Undo step.

**Show samples** or `/vg party preview` adds sample effects beside the members the game shows now. It doesn't add sample members. `/vg party live` ends the samples, and so does unticking **On**. While the buffs are off, **Show samples** says to turn them on first and changes nothing. Samples create no tracking or alert events.

Alliance rows show the effects Vantage sees land on alliance members. The game sends buff icons for your own party only. So an alliance member's row holds what Vantage saw cast on them, with estimated countdowns or none. It can miss what was cast out of sight. Copy Image there shows how many shadows are left (see **Shadows and Third Eye**).

**Light up debuffs you can remove**, on the **Show** tab, lights a debuff the way the panels do (see **Debuffs you can remove**). It starts off and uses the glow and color from **Lit icons** on the Overhead icons panel, so there's nothing else to set. Erase doesn't reach the alliance rows, so a debuff only it removes stays unlit there.

Party changes support profiles, Undo, Redo, **Reset this display** and `/vg reset party_ui`.

### Show

**Countdowns**, on the **Show** tab, shows the time left on each party buff icon. It starts off, so at first the buffs are icons only.

**Your own row** can be **Always**, **Only in a party** or **Never**. **Only in a party** hides the party list buffs while you're alone.

**Most per member** at **All that fit** keeps every effect that passes your filters. Any other number stops there. **Sort** offers **Longest remaining**, **Oldest first**, **Ending soonest** and **Name**. Longest remaining is the default. It sorts **4h**, then **3m**, then **57s**, and effects without a countdown go last. **Icons fill** picks the starting edge. Pinned effects come first.

While party cooldowns show beside the party list, a line says so. **Change on Party cooldowns** opens that panel. With **None** picked and no party cooldowns there, the line says nothing shows.

An effect with no known duration keeps its icon, with no countdown and no mark. Level Sync always shows only its icon. Your own effect timers use the client's durations. A complete icon snapshot from the game tells Vantage which effects are on same-zone members of your own party, even outside entity range, but it gives no duration. Applications you observe can add estimated timers. An empty row doesn't prove a member has no buffs. Your own KO doesn't clear what Vantage saw on other members. In an alert's **Who to watch**, **My party, including me** selects your group and **Other alliance parties** selects the other two groups.

### Size and place

Beside the game's list, each member's icons fill the step from one row to the next, centered on the member's row. So one member's icons touch the next member's. Where the step isn't a whole number of pixels, as with some game menu sizes, Vantage rounds the icons up. One member's icons may then cover the next member's by 1 px, but they never leave a gap. There's no space between the icons either. A line at the top of the **Size and place** tab says how big that is in your game. At 1920x1080 with the game menu at its usual size, the rows are 14 px tall and 20 px apart, so the icons are 20 px. With no one else in the party, the step comes from the game's empty party slots, or from a party earlier this session at the same row height. Until one of them gives it, the icons are as tall as the row and the line gives no number.

With **Original FFXI** or **XI View** party buff icons, Vantage makes each icon from its 32 px picture at the size it draws, so it stays sharp. A new size takes a moment. Until it's made, Vantage draws the 32 px picture scaled. **Client** icons are scaled to the size instead.

**Row width** holds **Longest row**. A group's row grows with its buffs up to that width, and it always has room for one whole icon. Effects that don't fit are left out after the last one that does, with no count.

**Icon size in a panel of its own** shows while a group that's showing is in a panel of its own. It sets how big the icons are there. A skin and a **Size** button keep it. **Size** doesn't change the size beside the game's rows. A smaller menu resolution in the game's own settings makes the game's rows, and the step, bigger.

While **Countdowns** is on, **Countdown size** shows too. **Countdown position** joins it while a group that's showing is in a panel of its own. **Countdown gap** joins them while **Countdown position** is **Below icon**. The countdowns use **Font** on the main page. Beside the game's list, the time sits inside the icon. A panel of its own uses the position and gap you pick.

**Buff side** puts each group on the left or right of its game window, including a group you dragged. **Gap from the game's list** is the space between the game's party list and the nearest icon. It starts at 26 px. **Icons fill** fills each row **Left to right** or **Right to left**, and you can still change it while Locked. Beside the game's list, a row stays next to the game's row either way.

Beside the game's list, a group follows the game's rows, which keep their own size and height. Each member gets one row of icons. To move a group, unlock first, then hold Shift and drag it from inside or from an edge. Vantage saves where it went. Dragging never puts a group in a panel of its own. **Put moved groups back** puts every group you moved back beside the game's list on the **Buff side**. If there's no room on that side, such as with a list at the screen's edge, the buffs don't show and a line on this tab says so.

**Panels of their own**, on this tab, has a switch for each group that shows: **Your party in a panel of its own**, **Alliance 1 in a panel of its own** and **Alliance 2 in a panel of its own**. Each one puts that group's buffs in a framed panel where the group is drawn now, and keeps the panel's edge next to the game's list. The panel is up to **Longest row** wide and as tall as its members' buffs need. It moves up if the screen has no room under it. In an alliance, a panel that would cover another group goes beside that group, away from the game's list. If there's no room beside it, the panel goes above it. With no room for either, the panels beside the list share the screen's height. They work while Locked. Turn one off to put that group back beside the game's rows. A panel has its own position and size. Member labels and effects wrap inside it, and scrolling reaches the rest. **Panel to edit** picks one, with **Panel width**, **Panel height**, **Across the screen** and **Down the screen**. Or unlock, hold Shift and drag the panel, or drag an edge or corner to resize it. None of these resize the game's windows.

While a group that's showing is in a panel of its own, a line under the panel's top line names it, such as **Your party is in a panel of its own.** Under that line is **Put party buffs back beside the party list**. It puts every group in a panel of its own back beside the game's rows as one Undo step, and it works while Locked. Each group keeps where you moved it, and each panel keeps its size and place for next time. **Snap back beside the game's list when released**, in **Panels of their own**, puts a panel back beside its group's game window when you let go of it there.

**Member order** shows then too, and it reorders a panel. Pick a group under **Group to order** and move its slots with **Up** and **Down**. The party itself doesn't change.

A group needs the client's row positions. If Vantage can't read a group's rows, it leaves that group undrawn instead of drawing it at a guessed spot. A member whose row isn't in the game's list yet, as just after a join, gets no icons while the others keep theirs. The **Size and place** tab and `/vg report` say why.

### Look

The party list buffs wear the timer panels' look. They use the skin, window frame, font and colors on the main page. A group in a panel of its own also uses **No boxes or headings**, **Background** and **Border**. Their own choices on the **Look** tab are **Opacity** and **Party buff icons**, which picks **Client**, **Original FFXI** or **XI View** icons.

**Member names** shows while a group that's showing is in a panel of its own. It sets how that panel names its members. You can pick the full name, a short name (with **Short name length**) or the job. If the client doesn't give a member's job, that member keeps the name.

### Filters

The **Filters** tab starts with a line saying the **Hidden everywhere** list applies here too. **Edit the list** opens it.

**Always show** has **Copy Image** and **Third Eye**, and both start ticked. Ticked, they show even with **Debuffs only** on. Unticked, they don't show. **Hide here** and the **Hidden everywhere** list still hide them. While **Show only** has effects on it, only those show. **None** shows no effects, so the line goes with them. Beside the game's list they still have to fit the row, and **Pin first** keeps one at the front.

**Find an effect** finds an effect, and **Effect** picks it for **Show only**, **Hide here**, **Pin first** and **Reset selected effect**. What you've put on each list shows by name under **Show only**, **Hidden here** and **Pinned first**. **Remove** takes one off there, and **Clear this display's filters** clears them all.

### When to show

**When to show** has the same rows as a timer panel's, plus two notes about what else hides the buffs. **Your own row** can hide them while you're alone. And they pause while the Treasure Pool's list or a lot/pass window is open, so they can't cover the lot/pass results. They come back when it closes. They also stop during fishing and the character preview, which draw the party window their own way.

## Overhead icons

Vantage can draw buffs and debuffs above heads in the game world. Overhead icons start off. Turn them on with **Overhead icons** on the main page or with `/vg overhead on`. **Edit** on that row opens the panel, and **On** at the top of the panel turns them on too. Nothing over a head can be clicked, so there's no lock. The icons sit under every Vantage panel, and the game gets the mouse as usual.

A block shows only what Vantage has seen. The game sends an action only to players within 30 yalms of whoever acts, and it sends a wear-off message only to whoever cast the effect. So debuffs that others put on a mob run on an estimate. If one of those runs out with no wear-off, it keeps its icon with no countdown. The game sends buff icons for your own party only, so blocks over the alliance and other players hold what Vantage saw land on them.

**Show icons over**, at the top of the **Show** tab, has a switch for each kind of unit: **Your target**, **Your subtarget**, **Mobs your party claimed**, **Watched mobs**, **Mobs your party debuffed**, **Party members**, **Alliance members**, **Other players**, **Your pet**, **Other players' pets** and **You**. Other players, their pets and you start off. While **Watched mobs** is ticked and nobody is watched, a line says so and has **Watch my target**. **Most units at once** keeps the most important ones, nearest first. It's 10 at first. **Farthest away** sets how far blocks go. It's 30 yalms at first and 50 at most. **Fade starts at** sets where they start to fade, and it's 20 at first. Blocks fade down to **Faded opacity** at the limit. Your target never fades. **Only your target and party in towns** keeps towns quiet. Sealion's Den isn't counted as a town. Each block stays fixed on its own unit. Where two overlap, Vantage draws the nearer one on top, and your target's is always on top.

A mob the game keeps out of sight never gets a block, even as your target. That covers an invisible one, a worm gone under the ground and an antlion buried in wait. When you load or reload Vantage, a mob that's already in view gets its block once the game next updates it, as when it moves.

**Change the settings for** picks the kind of unit that the rows after it change, and it shows on every tab that has such rows. Your target, your subtarget and the claimed, watched and debuffed mobs share the Mobs kind. A player you target uses their own kind. For **Layout**, **Single bar** puts debuffs, then buffs, in one row of 8 on mobs and the party. **Two lines** puts debuffs nearest the name and buffs above, or the other way around with **Swap the lines**. **Split** puts buffs on the left and debuffs on the right, or the other way around with **Swap the sides**. Each has its own limits, either **Icons shown** or **Debuffs shown** and **Buffs shown**. Vantage leaves out icons past a limit, the least important and newest first. Nothing marks that any were left out. In Split, mobs have **Crowd control icon on its own**. It draws Sleep, Silence, Petrification, Stun, Charm, Amnesia, Terror, Lullaby or Doom larger, next to the middle. Each kind also has its own **Show countdowns**, and its own **Show** with **Buffs and debuffs**, **Buffs only** or **Debuffs only**.

For mobs, **Light up buffs you can remove** lights a mob's buff in every layout when your job and level can take it off now. Dispel works from RDM 32, or /RDM with a main job of 64 and up. Magic Finale works from BRD 33, or /BRD at 66 and up. Blank Gaze works from BLU 38 while it's set. Dark Shot works from COR 40 with a Dark Card or Trump Card, a Marksmanship weapon (gun or crossbow) and its ammo. For Party, Alliance and You, **Light up debuffs you can remove** lights a debuff the same way (see **Debuffs you can remove**). It starts on. Erase reaches your party only, so on an alliance member a debuff that only Erase removes stays unlit. A lit debuff keeps its place among the icons.

The **Filters** tab goes by the kind picked too. It has **Use the Hidden everywhere list**, with **Edit the list** to open it, and **Only effects I cast**, **Only buffs I cast** and **Only debuffs from my party**. The last two are grey while **Only effects I cast** is on, and each is gone while **Show** leaves out the side it's for. It also has **Find an effect** and **Effect**, with **Show only** and **Hide here** for single effects. Those effects list by name under them. **Clear this kind's filters** clears those two lists. At first, mobs show your party's debuffs and their own buffs, and the alliance shows its debuffs. Your own block shows everything you have on. Everyone else shows their debuffs and the buffs you cast.

**Show these effects:** lists groups of effects for the kind: **Corsair rolls**, **Bard songs**, **Protect and Shell**, **Food**, **Barspells**, **Stances** and **Signet and similar**. That last group holds Signet, Sanction, Level Sync, Level Restriction, Reraise, Mounted and Battlefield. A ticked group shows and an unticked group hides, and the other filters still apply. An effect on the **Show only** list shows either way. Bust and the debuff songs aren't in a group, so they stay. Other players, party members, the alliance and pets start with Protect and Shell, Food and Signet and similar off. Mobs and you start with everything on. The list hides while **Show** is **Debuffs only**. What you ticked stays, and it decides nothing until the list is back.

**Always show** has **Copy Image** and **Third Eye**. A ticked effect shows whoever cast it, even with **Only effects I cast**, **Only buffs I cast** or **Debuffs only** on. It also comes first among the buffs, so a limit doesn't cut it. An unticked effect doesn't show. **Hide here** and the **Hidden everywhere** list still hide it. While **Show only** has effects on it, only those show. Mobs and you start ticked, and your party and the alliance start unticked. On a mob or an alliance member, Vantage follows Copy Image and Third Eye itself (see **Shadows and Third Eye**). Other players and pets don't have this line, because their icon wouldn't keep up.

Icons follow how big a unit is on screen, going by its distance from the camera and its size from Phoenix hitboxes. So a dragon's icons are larger than a goblin's. The **Size and place** tab holds **Icon size**, **Smallest**, **Largest**, **Bigger on your target**, **Shrink with distance**, **Bigger units get bigger icons**, **Crowd control icon size** and **Countdowns go inside icons under**. Those apply to every kind, and **Size** on the main page scales the icons too. **Icon size for this kind** is under **Change the settings for**. The same tab has **Where the icons sit**, which puts them above the name, or under the head for players who turn names off. It also has **Gap above the name** and the spaces between icons, lines and the two sides.

When icons sit above the name, Vantage reads where the game draws each name straight from the client every frame, and the target cursor over your target too. It puts each block **Gap above the name** over the name, over an icon in front of the name, or over the cursor when it's higher, near or far. That gap is 3 pixels at first. If the client can't be read that way, say after a client update, Vantage falls back to guessing. It also guesses for one unit that fails a check. The guess uses the head height, how far the middle of the name sits over the head, and how big Vantage takes the name and cursor to be. That distance is half a yalm for players at first, and none for mobs and pets. The sizes it takes for the name and cursor shrink with distance and stop growing up close. Those values, and the race heights, only matter for the guess, so they aren't on the panel. `/vg set` changes them. For the name, use `overhead.types.party.name_lift`, `overhead.layout.name_height` and `overhead.layout.name_cap`. The first of those is the party's, and each type has its own. For the cursor, use `overhead.layout.target_height` and `overhead.layout.target_cap`. `/vg report` says which way each unit's block was placed and why.

The **Look** tab has **Countdown color**. Bold, shadow, outline and the expiry blink are under **More look** on the main page. An effect with no known time shows its icon with no countdown.

**Lit icons**, on **Look**, has **Glow around lit icons** and **Light color**. They apply to every kind, and the party list icons use them too.

**If icons sit too high or too low**, on **Size and place**, starts closed. For the kind picked in it, it has **Head height offset** in yalms, and **Across** and **Down** in pixels. Under them, **Add head offset** raises or lowers the block over one unit, picked by its exact name. Type the name in **Unit name**, or fill it in with **Use my target's name**. `/vg overhead calibrate` prints your target's head height and where it comes from. The race heights, the hitbox line for mobs and the camera checks aren't on the panel. `/vg set` changes them by their path under `overhead`, such as `/vg set overhead.head.race_heights.8 2.2` for Galka.

Vantage reads the game's camera at the 2nd BeginScene of each frame, where the blocks hold still. If `/vg overhead calibrate` says the camera isn't in use because the frame had too few scenes, try `/vg set overhead.camera.capture present`. That reads the camera when the frame is shown. `/vg set overhead.camera.capture scene` goes back.

**Show samples** at the top of the panel, **Show samples** on the main page and `/vg overhead preview` show one block of sample icons above your name, where your own block would sit. It's laid out as the kind picked under **Change the settings for**. When you aren't on screen, it shows a third of the way down the middle of the screen instead. The samples draw over the settings window, and clicks go through them. They create no tracking or alert events. While the icons are off, the panel's **Show samples** says to turn them on first and changes nothing. **When to show** choices that hide the blocks leave the samples showing, and `/vg report` says the conditions hide them.

Blocks hide in cutscenes and events, on the map, while the game's interface is hidden and while zoning. A unit's block also hides while the unit is dead, not drawn or behind the camera. Overhead changes support profiles, shared presentation, Undo, Redo, **Reset this display** and `/vg reset overhead`. Picking a skin sets their countdown and light colors back to how they started, and has them follow **Font** on the main page. Their switches, layouts and filters stay.

## Party cooldowns

When Vantage sees a party or alliance member use a two-hour or a key job ability, it counts down that ability's recast for them. **Edit** on the main page's **Party cooldowns** row opens the panel. **On**, at the top of it, is the watch. The watch starts off. If you turn it on, there or on the main page, while the estimates have nowhere to show, the list turns on too. While the watch is off, Vantage counts nothing and keeps nothing, and the three places below show as off. Ticking one of them turns the watch on with it.

- It watches every two-hour of the jobs in era, and each of those is 7200 seconds on Phoenix. It also watches Provoke, Berserk, Warcry, Divine Seal, Martyr, Devotion, Elemental Seal, Convert, Sentinel, Rampart, Fealty, Chivalry, Call Beast, Nightingale, Troubadour, Meditate, Call Wyvern, Random Deal and Activate, with Phoenix's era recasts. Untick one under **Abilities to watch** to stop counting it, and **Watch every ability** ticks them all again.
- Each time is an estimate from the base recast. Merits can make some of them end sooner, and the tooltip says which. The game sends an action only to players within 30 yalms of whoever acts, so Vantage doesn't see a use farther off. Vantage doesn't count pets' moves. It doesn't count your own either, because your recast panels read those from the client.
- A Wild Card that lands on a member clears their job abilities. On a 5 or 6 it clears their two-hour too, unless their main job is COR. A job change clears all but the two-hour. Vantage drops a member who leaves the party.

The estimates show in three places, under **Show them** on the **Show** tab:

- **Beside the party list** starts on, so the party list buffs show the estimates once the watch is on. Each estimate is the ability's icon with its time left. They go first on the member's row beside the game's party list, nearest the game's window, before their buffs and debuffs. They draw on **Party list buffs**, so if that's off, or no group is ticked there, the **Show** tab says so and has a button to put it right. To show them with no buffs or debuffs, pick **None** on the **Show** tab of Party list buffs.
- **Over heads** starts off. It puts a line of up to six on the member's overhead block. A member with an estimate gets a block for it, even when their kind's filters leave none of their effects. They draw on **Overhead icons**, so if that's off, or **Party members** and **Alliance members** are both unticked there, the **Show** tab says so and has a button to put it right.
- **In a list** starts off. It's a display with one row for each estimate, with its member, ability and time left, in the timer panels' font and colors. **Sort** puts the ready soonest first, or sorts by member. **Filters** shows only the jobs you tick. **Most shown** and the list's height cut rows past them, with nothing after the last one. You set the height with **Tallest** on **Size and place**. The list starts locked. Turn off **Locked**, then hold Shift and drag it to move it, or drag an edge to resize it. While the watch and the list are on, **Show samples** shows sample rows that follow your **Sort**, **Filters** and **Abilities to watch**. While they aren't, it says to turn them on first. Like the alert notices, the list doesn't pause with the timer panels or follow **Hide timer panels while I type**. **Locked** and the **Filters**, **Size and place** and **When to show** tabs belong to the list, so they go away while it's off.

While the watch is on, the party list buffs' samples (`/vg party preview`) give their first five sample members a sample estimate each. A party or alliance block among the overhead samples gets a line of them too. That way each place shows in its normal look. With the watch off, they show none. Those samples belong to the party list buffs and the overhead icons, and they turn those on, not the watch.

`/vg reset party_cooldowns` or **Reset this display** restores all of it, the watch as well as the list.

## Phantom Roll

While you or a party member rolls, the Phantom Roll display shows the roll. It starts off. Turn it on with **Phantom Roll** on the main page. **Edit** on that row opens the panel, and **On** at the top of the panel turns it on too.

- Each roll shows its icon, its name and its total. The total is in the lucky color on its lucky number and the unlucky color on its unlucky number. At the right is the time left to **Double-Up**. That's 45 seconds from the Phantom Roll, and a Double-Up doesn't start it again. Vantage times yours by your Double-Up Chance and estimates another Corsair's from their roll. After a bust it shows **Bust** and the bust's time left, until the bust wears off.
- **Show what it gives** shows what the roll gives you at its total, from Phoenix's era roll tables, or what a bust takes from the Corsair. Vantage adds the job bonus only for a main job it sees in your party, on a total of 11 or less. Gear can also add it at random, and Vantage can't see that. When the Corsair's Corsair level is below your level, Vantage lowers the value the way Phoenix lowers it.
- **Show lucky and unlucky numbers** adds a line with each roll's two numbers. The total takes the lucky and unlucky colors either way.
- **Show the bust chance** shows the chance that one more Double-Up busts, based on the total. A Double-Up adds 1 to 6, and 12 or more busts. So a 6 busts 1 time in 6, and an 11 always does. With Snake Eye on the Corsair it adds 1, so only 11 busts.
- **Show who got it** shows your party in party order. Vantage dims members the roll didn't reach and those who already have the roll from another Corsair. After a bust, it also dims those who lost it. A roll reaches party members within 8 yalms of the Corsair, or 16 with Luzaf's Ring. The game sends an action only to players within 30 yalms of whoever acts, so Vantage doesn't see a roll farther off.
- It shows the numbers only and never says whether to Double-Up.
- The roll tables, what each roll gives and Snake Eye adding 1 are Phoenix's era rules, which the server plays with its content restriction (RESTRICT_CONTENT) on. Vantage assumes it is on.

Rolls go newest first. **Most rolls shown** and the display's height cut rolls past them, with nothing after the last one. You set the height with **Tallest** on **Size and place**. Members past the display's width are left out the same way. The display starts locked. Turn off **Locked**, then hold Shift and drag it to move it, or drag an edge to resize it. **Show samples** shows two sample rolls while the display is on, and says to turn it on first while it isn't. **Look** has its colors and **Show its heading**. It has no **Filters** tab. Like the party cooldown list, it doesn't pause with the timer panels or follow **Hide timer panels while I type**. `/vg reset rolls` or **Reset this display** restores it.

## Pet

While you have a pet, the pet display shows it. It starts off. Turn it on with **Pet** on the main page, and **Edit** on that row opens its panel.

- It shows the pet's name, and bars for its HP, MP and TP as the client has them. MP shows once the game gives the pet some, because a pet with no MP reads 0. A pet too far off for the client to show stays on the display with its effects, and the game keeps its HP up to date. If there's no word of it for 90 minutes, it leaves.
- **Effects** can be **Buffs and debuffs**, **Buffs only**, **Debuffs only** or **None**. It shows the effects Vantage saw land on the pet, debuffs first, with their countdowns. **Show effects as** draws them as **Icons**, which wrap onto more rows when they don't fit the width, or as a **List with names**. The list has one line for each effect, with its icon, its name and its time left over a fill of how much is left. An effect near its end blinks, as **Blink before an effect ends** sets for every display. The **Filters** tab has the display's own **Show only** and **Hide here**, and **Use the Hidden everywhere list**. The Pets group in that list matches your pet.
- **Show pet command recasts** shows your recasts of BST's Sic, Reward, Call Beast, Charm, Fight, Heel, Leave and Stay, SMN's Blood Pact: Rage and Ward, Assault, Retreat and Release, DRG's Call Wyvern, Spirit Link, Dismiss and Deep Breathing, and PUP's Activate, Repair, Deploy, Deactivate, Retrieve, Maneuvers, Role Reversal and Ventriloquy. On those jobs it also shows your main job's two-hour. The soonest ready go first. The time is the client's own. A fill shows how much of the full recast is left. The full recast is the one Vantage saw start, or else Phoenix's era recast less your merits on that main job, such as Sic's 120 seconds less 4 for each merit and Repair's 180 less 3. The game sends your merits as you zone. So after `/addon reload vantage`, the fill of a timer that's already running counts no merits until your next zone. Ready isn't in this era, so its timer is Sic alone. Repair's flat 180 and Ready staying out are Phoenix's era rules, which the server plays with its content restriction (RESTRICT_CONTENT) on, as Vantage assumes.
- **Show maneuvers and overload risk** shows a line for each element with a maneuver up, when you're a PUP, main or support. Each line has its icon, its name, a square for each maneuver, the time until the next of them ends, and the overload risk your last maneuver of that element reported. The risk then falls by 1 every 3 seconds, which is the slowest the server lowers it. So the real risk is at most what's shown.
- **Show charm and jug time** gives an estimate of the time left for a pet you charmed. It comes from Phoenix's charm formula, with your CHR, your main level, the mob's level and the charm time gear you had on. The mob's level is the one a /check before the charm gave. Without one, the charm shows with no countdown. Familiar adds 25 to 30 minutes once, and the estimate counts 25. For a jug pet, **Leaves in** shows Phoenix's time for that pet, counted from your Call Beast. It's in the warning color for its last minute. Familiar doesn't change it. A zone change keeps the clock only if the same jug comes back within 30 seconds, and a jug that was already out when Vantage loaded has no clock. The display shows a pet for as long as the game does, through a zone change too. `/addon reload` keeps a jug's clock and a charm's estimate for as long as the game runs, without writing anything to disk.

The game sends no list of a pet's effects. When an effect on a pet ends, the game tells only the player it came from, so only effects from you end exactly. These have a length Vantage knows, and they leave at your wear-off or on time:

- Reward and Repair's Regen, Deep Breathing's Magic Atk. Boost on your wyvern, and Overdrive and overload on your automaton, which take the time of your own.
- What Empathy copies with Spirit Link, each with the time yours had left. When you have more of them than ranks, the server picks at random, so then none shows.
- Your avatar's wards, with the time of your own copy from that ward, or else the length from your summoning skill and level. With neither, there's no countdown.

A level restriction or Level Sync takes every effect off a pet you called, and the game says nothing about it. So Vantage clears them when your level changes with one of those. A mob you charmed keeps its own.

What Reward, Repair and Spirit Link cure leaves when you use them. A hit wakes your pet, as it wakes a mob, and takes the time off Bind, but a mob's Nightmare stays. The rest are estimates. One whose estimate ran out shows with no countdown and leaves as other estimates do.

What your pet does counts as yours. **Only effects I cast** and **Only buffs I cast** keep it on the timer panels and overhead icons. **Also list enemies I debuff** lists the mobs it debuffed, and the effect's tooltip says it came from your pet. Learned times still come from your own casts alone.

**Most effects shown**, **Most recasts shown**, the display's width and its height cut what's past them, with nothing after the last one. It starts locked. Turn off **Locked**, then hold Shift and drag it. **Show samples** shows a sample pet of your job. **Look** has its bar colors. Like the party cooldown list, it doesn't pause with the timer panels or follow **Hide timer panels while I type**. `/vg reset pet` or **Reset this display** puts it back as it started.

## Recasts

Open the Recasts panel with **Edit** on the Recasts row of the main page, or type `/vg recasts`. **Show as**, on its **Show** tab, chooses **A panel for each kind** or **One panel for all**. A panel for each kind is the default. It has separate spell, ability and equipped enchanted-item panels, and they start off. Tick the ones you want on the main page, or type `/vg recasts show` to turn on all three. **Editing** picks which of the three the tabs change.

Choose **One panel for all** or type `/vg recasts combine` to put your cooldowns in one panel. The ticks on the main page choose which spell, ability and item rows it includes. The one panel has its own filters, sorting, pinning, labels, fields, look and placement. Those settings don't change the three separate panels. Type `/vg recasts separate` to go back to their saved layout.

`/vg recasts show` and `/vg recasts hide` work on whichever way is in use. Hiding or switching keeps the other layout and the alert rules. The one panel starts on when you choose it, and **On** can turn it off.

Recast panels start as thin rails, with a dark area behind their text. Cooldown settings use **Ready soonest**, and **Ready soon** on **Look** colors a recast near the end. **Reset this display** restores only that panel. It leaves the way recasts show and the artwork as they are.

Each panel has the same controls as status timers: bars, expanded bars, icons and text layouts, row parts, colors, filters, custom labels, order, groups, pinning, moving with something and placement. Shift drag and resize a panel to wrap its contents. **Text** shows one row for each recast, with its name and countdown and no icon or bar. You can't show or hide its parts. Labels, dividers and colors still apply, and the parts you show stay saved for the bar layouts.

**Icons show** picks **The effect it gives** or **The spell or ability**, and the effect it gives is the default. With the effect it gives, a spell or ability that gives a buff or debuff, such as Protect, Paralyze, Dia, a song or Sneak, shows that status icon in your **Icons** artwork. Most job abilities show their status once you've used them this session. Abilities with no status, shared timers that could be several actions, and items keep their own picture. So does a status whose picture is missing.

Otherwise, recast rows use the client's spell, ability and item pictures. Spell and ability icons keep their native tier markings and component colors. Choose **Recast icons**, under **More look** on the main page, for **Original FFXI** or **XI View** action artwork. Missing XI View artwork falls back to stock. Item pictures come from the client resource manager whatever you choose there. Artwork stays in your installed client, and Vantage doesn't bundle any game images. Five ninjutsu spells use an approximate icon shadow, because the addon renderer can't do their native subtractive blend. Their foreground artwork still comes from the client.

Shared ability timers use the actions known right now, when the client gives that information. If several actions have different pictures, the icon group shows up to four different pictures. Hover it for details that name the shared timer. A recast with no client artwork keeps an empty icon box. It never borrows an unrelated status icon. Which icon shows doesn't change a cooldown's length or how Vantage tells it's ready.

Cooldowns come from the local client's clocks. Shared ability timers show resource names together. The job-special timer doesn't assume a one-hour or two-hour length. Vantage doesn't work out charge counts, so a charged ability may be usable before its full timer ends. For items, Vantage covers eligible enchanted equipment you're wearing now, including the equip delay. It doesn't scan all your bags or track ordinary consumables. Items with no charges left don't announce that they're ready.

When Vantage loads, it knows the time left on a cooldown that's already running, but not its full length. When Vantage sees a cooldown start, bars use the first time left it saw. A projected countdown that reaches zero waits for fresh word from the client. Missing or unreadable slots stay uncertain, and they don't set off a ready alert.

On **Alerts**, set **Alert type** to **Recast**. Pick a spell, ability timer or item, or **All recasts**, then set **Trigger** to **Recast started**, **Recast ready** or **Time running low**. The usual visual notices, row emphasis, local chat, optional sounds, conditions, cooldowns and test controls apply. Percent thresholds need an original length that Vantage saw. Loading, zoning or changing jobs sets a quiet baseline instead of replaying old starts. **Recast ready** tells you the cooldown ended. It doesn't promise the MP, charges, range or anything else you need to use it.

Categories you aren't using stop polling, unless an alert that's on needs them or their settings catalog is open. Active categories sample at most every 100 ms. Countdowns move on between samples without extra client reads.

### Recast marks

A recast row tints while it couldn't be used. It does this in every layout (bars, expanded bars, icons and text) and with one panel or several. A tint goes under the row's text, so the countdown always shows. Each mark starts off. Each has its own tick and color in the **Mark recasts I can't use right now** fold on the panel's **Show** tab, and that fold shows while a recast panel shows spells or abilities.

- **Spells while my MP is too low** turns a spell row blue while your MP is below the spell's cost. The cost is the era one Phoenix uses. Phoenix's era settings change the cost of 54 elemental nukes and of Raise II and III and Reraise II and III, so those use Phoenix's numbers. Every other spell uses the client's. Manafont stops the tint. Songs and ninjutsu cost no MP. Vantage doesn't count gear that lowers the cost.
- **Spells while Silenced or Muted** turns spell rows grey and shows a lock. The lock's time left comes from your own status timer. When the game gives no time, the lock shows with none.
- **Abilities under Amnesia** does the same to ability rows while Amnesia is on you.

In Salvage, Omerta locks every spell and Impairment locks abilities, as Phoenix puts them on at the entrance. In Nyzul Isle they stop only some kinds of spell or move, and the game doesn't tell the client which. So they lock nothing there. Hover a row to read why it's tinted. Item rows never tint. With **Show samples** on, the sample Cure IV row shows the MP tint, and the sample Haste and Provoke rows show the spell and ability locks. That way you can see each color, for the tints that are on.

With no icon on the row, the lock and its time go just before the countdown, and the spell's name stops short of them.

### Ready pulse

When a recast of a minute or more becomes ready, its icon grows and fades once. The pulse starts off. To turn it on, tick **Ready pulse** on the main page, or **Pulse when a long recast is ready** in the **Ready pulse** fold on the Recasts panel's **Show** tab. You set it up in that fold:

- **Only recasts of at least** is 60 seconds at first. A recast's length is its full cooldown if Vantage saw it start, or else the most time it saw left.
- **Start early** sets how many seconds before ready it pulses. It then pulses that early, once, and not again at ready.
- For **Pulse spot**, **On its row** pulses where a recast panel last drew that recast, over the panels. If no recast panel is on, the fold says so and has **Use a spot of its own**. **A spot of its own** pulses at a spot you place, whether or not a panel shows the recast. It also pulses there while the timer panels are paused or hidden by **Hide timer panels while I type**. The spot starts locked, and holding Shift shows where it is. To move it, turn off its **Locked** on the **Size and place** tab, then hold Shift and drag it, or set its **Across** and **Down** there. **Show a test pulse** plays one with a sample icon.
- The fold also has **Pulse size**, **Pulse color** and **Pulse for**.
- **Never pulse for** lets you pick recasts that never pulse. **Pulse again** takes one off the list.

The pulse only draws. It takes no clicks and makes no sound. Recast alerts on **Alerts** still give notices and sounds.

## The Filters tab

Open a panel's **Filters** tab.

**Find an effect** searches by name. Typing an effect's number finds it too. The lists hold the effects that can exist on Phoenix. An effect you already picked stays listed while it's saved. **Show only** makes an allow-list when at least one effect is ticked. **Hide here** takes priority. **Pin first** keeps an effect above ordinary rows. **Rename it** changes the name that shows, but it's still the same effect. Hovering the effect shows the new name too.

**Add to My order** puts an effect on the list for **My order** under **Sort**, and **Up**, **Down** and **Remove** arrange it. Effects you didn't list follow the ones you did. With nothing on the list, rows go by name and a line says so. **Group rows** on **Show** groups the rows by target or effect group when that's useful. Each effect can have its own **Color**. It shows on a bar, or on a countdown while **Color each countdown by how sure Vantage is of its time** is on.

## Alerts

**Alerts** on the main page starts on. **Edit** on that row opens its panel. On **Show**, **Haste reminder**, **Sleep reminder** and **Silence notice** each add a ready-made alert, and **New alert** adds one you set up yourself. Click a reminder again and it turns its alert back on and opens it. **Your alerts** lists them by name. The tick turns one on or off. **Edit** opens it below and **Done** closes it. **Copy** adds a copy. **Delete** takes it away, and Undo brings it back.

An open alert has **Rule name**, then **What**, **Who**, **When to alert** and **How to alert**, which cover the effect, who to watch, when it fires and what it does. **Only on these main jobs** is a fold at the end of **When to alert**. It limits the alert to the jobs you tick, and a line under the fold names them. **Flash the bar** shows while **Make the effect's bar stand out** is on. Use **Test this alert** to try the selected output without applying a real effect.

**Quiet during cutscenes** and **Sound volume** are above the list. **Size and place** has **Width**, **Tallest**, **Notices shown at once** and where the notices go. **When to show** sets when they show. There's no **Filters** tab, because each alert picks its own effects. **Reset this display** puts all of Alerts back the way it started, your alerts too. That's why it asks first and says how many. `/vg reset alerts` does the same without asking, and Undo brings them back. `/vg mute` mutes notices and sounds. Then the **Alerts** row and the top of the panel have **Unmute**.

- **Effect gained:** Vantage sees an application, or a status that's newly there, after the quiet startup baseline.
- **Time running low:** a current timer crosses a threshold you picked. Seconds work when the time left is known. Percent needs a known original total. Switching **Threshold unit** to **Percent remaining** keeps any thresholds up to 100. If there aren't any, it uses 10.
- **Effect removed / wore off:** Vantage sees a removal, or a complete status snapshot shows the status is gone. It doesn't tell an effect that ran out from one that was cancelled, dispelled or removed some other way, unless the evidence does. Recasting a buff before it ends counts as a refresh and fires no **Effect removed / wore off** alert. That includes a Refresh recast on a party member.
- **Required effect missing:** an effect isn't in a status snapshot of the one the rule watches, and that snapshot is known to be complete. Choose a specific effect. An unknown or out-of-range state doesn't count as missing. An effect that's missing from the start has a short settling period before its first warning. **Required effect missing** rules can't prove an enemy lacks an effect Vantage hasn't seen.

Remaining-time alerts on anyone but you go by estimates. That's why their notices are marked estimated and can arrive after an effect ended early. Percent rules skip modeled duration ranges, because those don't give a known original total. If one update crosses multiple thresholds, you get the most urgent notice. Each threshold fires once for each application. **Repeat reminder** can remind you while the condition goes on, and **Minimum time between repeats** spaces those reminders out. A refresh clears stale notices. A reload, zoning, a death, rule edits and unmuting don't replay old threshold crossings. A repeat interval keeps going after an event, a death, a zone change or a mute. It counts from when that ended. With no repeat interval, Vantage tells you about a missing effect once each time it goes missing. That's also true when it goes missing during an event or a mute. A zone change or a pause of more than 10 seconds starts every rule over. So if an effect is still missing then, Vantage tells you again.

Visual notices and row emphasis are local. Vantage prints chat output only in your own client. Sounds are optional and start unselected. Put your WAV or MP3 files in the settings folder's `sounds` subfolder. Then refresh the list, select a file and test it. Each rule can follow **Sound volume** or have its own. Bar emphasis can flash in a color you choose, for as long as you choose. Vantage limits warnings that go off at the same time to one sound per second. A rule at volume 0 plays no sound and leaves that one to another rule. It doesn't matter whether that volume is its own or the **Sound volume** it follows. Vantage doesn't bundle any audio files.

## Timer durations

**Timer durations** changes how long Vantage counts the effects it estimates. Those are the effects on mobs, party members and other players. Your own effects follow the game's timers and never change here. Click **Timer durations** beside the search box at the top to open it.

**Duration overrides** sets your own time for a spell, a job ability or an effect. Pick one with **Override applies to**, **Find what to override** and **What to override**, then click **Add duration override**. A new override starts at a fixed 60 seconds. **Change the time to** works on the one you picked under **Override to edit**. It can be **A fixed time** (**Fixed time**), **Add or take away seconds**, **A percent of the estimate**, or **Count up from when it landed**. That last one shows the time since it landed in place of a countdown. **Only on a mob or player named** keeps the override to one mob or player by its exact name, and **Use my target's name** fills that in. A rule for a spell or ability goes before one for its effect. A rule with a name goes before one without. An overridden time is still an estimate, and its details say so. A count up has no time left, so **Only effects with a known time** hides it and **Time running low** alerts skip it. It stays listed as long as the estimate it hides would.

Under **Learned durations**, **Learn from my casts** starts off. With it on, Vantage keeps the time from when it sees an effect of yours land on a mob or another player to its wear-off. The times go by spell and by mob name, and players share one time for each spell. Vantage keeps up to nine for each, the newest ones. Once there are enough times for **Casts before a learned time is used** (3), your casts of that spell on that mob count down from the middle one. Their details say the time is learned and estimated. Other people's casts keep the usual estimate. An override still goes first. With learning off, the times stay saved but aren't used. Phoenix checks for expiry every 0.4 seconds, so a learned time can read up to 0.4 seconds long. A resisted cast is shorter. That's why Vantage uses the middle one. The client can't tell a mob's family, so learning goes by name.

Vantage learns nothing from these ends: a removal it saw, an end with no wear-off (a death, Dispel, a zone change), a sleep woken by a hit or running beside a damage tick, a Bind that took a hit, and another caster's copy over yours. Recasting your own starts its clock again. Phoenix sends you the wear-off just before the hit, removal or new copy that ended it, so Vantage waits a second before it learns a wear-off. Any of those in that second keeps it out.

Vantage saves at most 128 learned times in each character's settings file. **Clear learned durations** forgets them in one Undo step. They aren't settings, so every other Undo and Redo step, **Reset this page**, `/vg reset`, profiles and shared presentation keep this character's own. Profiles and shared presentation carry the overrides and the learning switches. `/vg reset durations` resets this page.

## Edit mode

**Edit mode** lets you place every display at once. Turn it on with `/vg edit` or **Edit mode** under **Moving** on the main page. Every display on the screen gets an outline, with its name just above it. A bar at the top of the screen holds the one you pick. Overhead icons sit over heads in the world, so they aren't in edit mode. A display that's off has no outline until you turn it on. In edit mode, a display shows even when it's empty, out of combat, while you type, or where its **When to show** choices would hide it. That way you can place it. The bar says when those choices would hide it.

- Click a display to pick it. Hold Shift and drag to move it. It goes exactly where you drag it, unless Grid mode is on and the display is ticked for it.
- **Grid mode** is under **Moving** on the main page, and it starts off. While it's on, **Grid and snapping** under it has **Tick the displays that snap:** and a tick box for each display that's on. None are ticked at first. Then come **Grid size**, **Show the grid**, the five **Snap to** switches and **Snap distance**. While Grid mode is on, the bar has **Use Grid mode** for the display you picked. It's the same tick as the display's own on the main page, and it works on a locked display too. The bar also has **Show the grid**, **Grid** and, after **Line up with**, the same five switches. Each tick and each turn of the switch is one Undo step. A display you turn off leaves the list but keeps its tick. Turn it on again and it shows ticked.
- A ticked display snaps as you drag it. That works in edit mode, or with Shift outside edit mode once it's unlocked, and it includes the party list buffs. As the switches choose, it snaps within **Snap distance** to the grid, the screen's center and edges, the other displays' edges and middles (not those that follow it), the game's party list and the chat log. It snaps to the last two where Vantage can read them. A resize snaps the edge you pull while the edge across from it stays put. The line it snapped to shows while you drag, and so does the grid while **Show the grid** is on. Both go away when you let go. With every **Snap to** switch off, nothing snaps.
- While the bar or a picked display has focus, the arrow keys move it 1 px, or 10 with Shift. Edit mode takes the keys only then, through ImGui. The bar doesn't take them when it opens, so click it or a display first. Click the game to give them back. Arrow presses less than about half a second apart count as one move.
- **Moves with** in the bar says what the display follows. **Size and place** opens that tab, where you type its spot or pick what it moves with. A number you type in **Grid** takes effect when you press Enter or click away. Typing alone changes nothing. Pressing Escape while you type in it puts its number back and keeps edit mode on. The next Escape ends edit mode. Its - and + buttons take effect at once.
- You can pick a locked display and look at it, but nothing moves it, and Shift never does. **Locked** in the bar unlocks it or locks it again. The party list buffs share one lock, and they move by their offset from the game's party window.
- Each move is one Undo step. A move is a drag or a run of arrow presses. The bar has **Undo** and **Redo** too.
- **Done**, `/vg edit` or Escape while the bar has focus ends edit mode. Every display stays where it is. In edit mode, a click picks a display.

**Moves with** on a display's **Size and place** tab keeps the display beside something. That can be a spot on the screen (a corner, an edge or the center), another display, the game's party list (your party's window) or the chat log. A spot keeps the display's same corner or edge **Across from it** and **Down from it** of that **Spot**. That way it stays put when the screen size changes. The other choices put it on a **Side** of what it follows, with a **Gap**. It lines up with its near end, middle or far end (**Line up**), and **Along the side** moves it along that side. In edit mode, moving a display that moves with something keeps what it moves with and changes those distances, up to 300 pixels from it and 2000 along the side. Past that, it says so. To place it freely, set **Moves with** to **Nothing**. A display can't follow one that follows it back.

The chat log and the game's party list sit at the bottom of the screen. If you pick one while **Side** is on Below, **Side** moves to Above or Left. A spot on the screen starts where the display is now.

The display goes to its own **Across** and **Down** while what it follows isn't on the screen (an empty or hidden display, or a party list or chat log Vantage can't read). It also goes there when there's no room on that side of the chat log, and a line on that tab says so. Outside edit mode, a Shift drag ends **Moves with**. **Nothing** under **Moves with** and **Put it back where it started** are one Undo step each. Profiles and shared presentation carry **Moves with**, Grid mode, its ticks and the grid. Placement sharing carries what each panel moves with. `/vg reset layout` resets Grid mode, its ticks, the grid, snapping and **Moves with** on every display. `/vg reset moves_with` resets only **Moves with**, and `/vg reset edit_mode` resets only Grid mode, its ticks, the grid and snapping.

## When to show

**When to show** sets where and when a display shows. Every display has it as its last tab. The ready pulse has **When the pulse plays**. It's a fold on that tab of the Recasts panel. The conditions are:

- **Main job** and **Support job** match any of the jobs you check.
- **Level**, **From** and **To** go by your main job's level as the game shows it, which is lowered under Level Sync or a level cap.
- **Level Sync** shows it only while you're Level Synced, or only while you're not.
- **Where** matches any of the kinds you check. **Towns**, **Fields** and **Dungeons** are Phoenix's own zone types. The ferries to Selbina and Mhaura and the battlefield arenas have no type and count as **Other zones**. The airships and the pirate ferries are fields. **Battlefields** is the Battlefield status. The game gives you that status when you register for a battlefield and keeps it until you leave the battlefield. So a fight in Ghelsba Outpost is a dungeon and a battlefield. **Dynamis**, **Limbus**, **Assault**, **Salvage**, **Nyzul Isle** and **The Ashu Talif** are those zones. **Mog House** comes from the zone you entered. While you're in one, the town around it doesn't count. After `/addon reload` in a Mog House, Vantage knows it at the next zone.
- **Party** has **Solo**, **In a party** and **In an alliance**, as the game's party list shows it.
- **Fighting** shows it only while you're engaged or only while you're not. **Pet** shows it only with a pet out or only without one.

Every condition you set must hold. A condition with several picks holds for any of them. A display with none always shows. The tab says the display's conditions in plain words, and where you are now, such as `Now: WHM 75 / BLM, in a dungeon, in a party, not engaged, no pet.` Conditions hide only the display. Tracking and alerts go on, and while the alert notices are hidden, a rule's chat line and sound still play. Show samples and edit mode show a display anyway, but edit mode doesn't place overhead icons. The ready pulse has a test pulse in place of samples. **Clear these conditions** on that tab is one Undo step. Profiles and shared presentation carry them, and `/vg reset conditions` clears them all.

## Import and export

**Import and export**, on **Profiles and sharing**, copies part of your settings as text for a friend to import into their Vantage. Pick what to send under **Export**: **Whole profile**, **One display** (picked under **Display to export**), **Where everything is**, **Hidden everywhere list** or **Alert rules**. Then click **Copy**. It goes to the clipboard and nowhere else.

An export looks like `VG:1:1a2b3c4d:{...}`. That's a short prefix, the version, a checksum and then the settings as JSON. It holds settings only, never character or entity ids or file paths. Vantage takes out the names of your own characters, and your Windows name too. It looks for them in what you typed, such as titles, labels and rule names, and in sound and font names. So a setting or a skin that shares its name with your character stays. A whole profile looks for every character with a settings folder on this PC, and the other kinds look for the one you're playing. Vantage leaves out a hide rule that names a character, yours or anyone's, and an alert rule for one party member. It leaves out the whole rule, since without that name it would reach everyone. The page says when it does. No export holds a display's lock. One display's export also leaves out that display's switch and its samples.

To use one, copy it, then click **Import from clipboard**. Vantage refuses an export from another version or one whose checksum doesn't match. It also refuses one longer than 256 KB or nested too deeply, and one that holds a setting Vantage doesn't have. Vantage cleans the entries of a list in it, such as the effects a panel shows, the same way it cleans a saved setting's. It reads the data with its strict JSON reader and never runs it. When Vantage can read an export, it shows what the export holds and what **Import and add** and **Import and replace** would change. **Import and add** keeps every setting you changed and takes the rest from the export, or adds its rules after yours and skips any you already have. **Import and replace** puts what the export holds in place of yours. Either is one Undo step. Both tidy every value the same way Vantage tidies a saved setting, and both keep your own locks, samples, diagnostics settings and chat colors. One display's export keeps that display's switch yours. A whole profile brings over which displays are on. Sound files aren't in an export, so a rule that plays one needs the same file in your `sounds` folder.

You can copy an export from Discord or chat as it was posted. Vantage skips code marks, quote marks, line breaks and any text around it, and the checksum still catches a change inside it. An export of another version, or one that holds a setting this Vantage doesn't have, was made with a newer Vantage. The page says "This was made with a newer Vantage. Update Vantage to read it." To keep a whole profile as a new saved profile instead, use **Save as a new profile** under it (see Appearance and profiles).

## Appearance and profiles

This affects status timers, recasts, the party list buffs in a panel of their own, party cooldowns, Phantom Roll and Pet together. To hide only the timer-panel backdrop and keep headings and borders, turn off **Background**. For one panel, pick its **Box** on its **Look** tab.

For the original client look, pick **Original FFXI** as the **Skin**. It pairs the skin with the Original FFXI font and artwork and thin gauges. It resets panel color overrides and bar sizing, and keeps placement, fields, filters and alert rules. Undo restores the previous appearance.

Original FFXI and XI View offer all eight client window types. **Window frame** changes the background and frame of every display and this window.

This window follows the skin. Its colors, frame and font come from the skin. **Settings text size** is the size of its text. With the Original FFXI or XI View font, the window draws its text at 16 or 32 pixels, whichever is nearer that size. That's because those fonts are made on a 16 pixel grid and blur at any other size. The size you set is kept. **Window Type 7**, the light cream frame, uses readable dark menu text and lighter controls.

Original FFXI reads the window backgrounds, frame pieces, gauges, and bitmap font from your base client files. Classic FFXI is a plain color skin and uses none of those. Original FFXI is the starting look. To use XI View, pick **XI View** as the **Skin** on the main page. This keeps your layout sizes. Reload Vantage after you change the installed artwork files. These choices don't change the selected window type or copy the game's layout settings.

XI View font, gauge artwork, and buff icons are independent options when an XI View overlay is set up. They use the installed replacement assets without changing the game, and the overlay doesn't need to be active. Under **More look**, choose **Gauges** for timer bars. Font choices stay independent. XI View changes the stock pairing. If files are missing or unsupported, the main page explains the readable fallback. Reload after you install or change these files. Vantage bundles no game textures or fonts. For icons, choose **Icons** under **More look**, or **Party buff icons** on the **Look** tab of Party list buffs. **Client** uses the images from Ashita's resource manager as they are. **Original FFXI** reads the base client icon files. **XI View** reads the installed overlay you set up. A missing XI View image falls back to stock and then to Client, and a readable placeholder shows if no image is available. These choices don't switch the game's icon pack. Vantage doesn't hide or replace any of the game's windows, nameplates, targeting arrows or cast indicators.

Client bitmap fonts apply to timers and alert notices. At startup, Vantage builds this window's matching fonts locally from those glyph shapes and caches them under the settings folder's `cache/client-fonts` subfolder. If that fails, this window uses its plain font, and a line under **Font** says so. When the client file a font comes from changes, its new font replaces the old one in that folder. If a client file can't make a font, Vantage notes it there and doesn't try that file again until the file changes. The window rasterizes its text, so its shading differs from the bitmap timers. Bitmap HUD text uses the original client texture with whole-pixel positioning. The client choices cover English text. Unsupported characters use a fallback glyph. Original artwork uses fixed frame corners. Its color controls tint the artwork, and white keeps the texture colors as they are. Custom gradients use the regular bar drawing. **Size** stays adjustable to suit your client interface. This skin uses the actual client artwork, but exact game text spacing and compositing aren't guaranteed. Menus keep the editor's working title bar, resize handles, inputs, and color picker. Their interactions and controls aren't the game's native menu engine.

Choose Phoenix, Classic FFXI, Original FFXI, XI View, Frameless, High contrast, Ember, Mint, Lavender, or Colorblind safe, then adjust individual colors. The 17 font choices are Ashita (Agave), Segoe UI, Arial, Tahoma, Verdana, Calibri, Consolas, Segoe UI Semibold, Tahoma Bold, Segoe UI Bold, Verdana Bold, Arial Bold, Calibri Bold, Trebuchet MS Bold, Bahnschrift, Consolas Bold, and Georgia Bold. Original FFXI and XI View add client bitmap choices for panels and matching generated menu fonts. There are controls for font, HUD and settings text sizes, scale, spacing, icon size, transparency, background, rounding, and border. Fonts use available installed resources and fall back when a selected face is unavailable. Put custom TTF or OTF files in the settings folder's `fonts` subfolder, then run `/addon reload vantage` to add them to the list. Vantage leaves a file out of the list if it's cut short, damaged or not a font, and `/vg report` says why. Custom font files stay outside the release package.

One font serves every display and this window. Name, countdown, and detail text can use their own colors. Outlines and shadows are optional.

### Expiring effect icons

By default, buff and debuff icons blink during their final 15 seconds. They use the client's dim-to-bright pulse. Icons keep their opacity, and countdown text stays steady. This works with Client, Original FFXI and XI View artwork in status panels and the party list buffs. An effect blinks if its time left is known or estimated, whether or not its countdown shows. So the party list buffs blink with **Countdowns** off too. Effects with no known time, estimates that ran out, permanent effects and Level Sync stay steady. Recasts are separate.

**Blink before an effect ends**, under **More look** on the main page, turns blinking on or off for the status timers, the party list buffs, overhead icons and the pet display together. The seconds beside it say when it starts. Each display keeps its own choice underneath, so what you saved stays as it is. While they differ, the tick reads partly on or the seconds read **Mixed**. If you pick something then, Vantage first names the displays it would change and waits for **Change** or **Cancel**.

You can set the threshold from 1 to 300 seconds. Countdown styling, alert rules and the status panels' ending-soon colors keep their separate settings. The animation uses a shared 0.7-second clock cycle, with no extra client polling.

### Countdown text

You can keep your selected font, including Original FFXI or XI View, and style just the remaining-time text. Names and menu text stay as they are.

**Countdowns**, under **More look** on the main page, styles the countdown text for every display at once, with **Bold**, **Shadow**, **Outline** and **Outline color**. **Usual for each display** is the **Outline** a new install has. It outlines the status panels and the party list buffs, and leaves recasts, overhead icons, Phantom Roll and Pet plain. **Every display** outlines them all, and **None** outlines none. Each display keeps its own choice underneath, so what you saved stays as it is. While they differ, a tick reads partly on and the others read **Mixed**. If you pick something then, Vantage first names the displays it would change and waits for **Change** or **Cancel**. Undo restores each display's choice. **Other text**, under it, has **Shadow**, **Outline** and **Outline color** for names, headings and the rest.

Where the countdown sits stays with each display:

- **Timer and recast panels** have **Countdowns on icons** on the panel's **Size and place** tab, where the rows are named **Size**, **Position** and **Gap**.
- For **Party list buffs**, turn on **Countdowns** on the **Show** tab, then use **Countdown size**, **Countdown position** and **Countdown gap** on its **Size and place** tab. **Countdown size** applies to every group. Position and gap apply to a group in a panel of its own.

When the display uses icons, these rows offer the choices below. On Party list buffs, **Countdown position** and **Countdown gap** show only while a group that's showing is in a panel of its own. Beside the game's list, the time sits inside the icon.

- In **Position**, **Below** centers the text below the icon and is the default. **Inside** places it within the lower edge. On Party list buffs, they read **Below icon** and **Inside icon**.
- In **Size**, **Automatic** or **0** uses half the rendered icon size, within 6-64 pixels. A value from **6-64** sets a manual size without changing the rest of the frame text.
- **Gap** adds **0-16** pixels below the icon. The default is **0**, with no extra gap. This control appears when the text sits below the icon. Switching to inside keeps the saved gap for later.

Original FFXI and XI View icon countdowns trim the transparent padding around their native glyphs. Layout uses the visible text bounds, including any bold, shadow or outline you picked, to keep the timer close to its icon. Skins and profiles keep explicit inside placement and manual sizes. Effects with no countdown and Level Sync still show the icon without a timer or mark.

Vantage removes the client fonts' built-in dark shading only from the prepared countdown glyphs, so turning shadow off works for Original FFXI and XI View too. Bold uses the selected glyph shapes. It doesn't switch to a different font. These choices work with icons, bars and text, including wrapped countdowns. The separate icon countdown size and placement controls apply only to icons.

**Icon size**, under **More look** on the main page, controls status and recast panel icons. Timer rows grow to fit the chosen icon size instead of shrinking icons to a shorter row. Party list buff icons don't use it. Beside the game's list, they fill the step between its rows, and a panel of its own has its own size on the panel's **Size and place** tab.

Search opens the matching controls. Sections remember whether they're open. **Hold Shift to see through this window** lets you look at panels under the editor while you arrange them. It starts on. Chat typing still blocks placement.

Visibility options cover events, the map, hidden game UI and typing. Vantage keeps only so many entities and lets old uncertain rows go. Letting them go never sets off a missing or removal alert.

**Profiles and sharing** holds your saved profiles, sharing across characters, **Import and export** and **Start over**. Its first line says which profile you're using and whether it changed since you saved it.

Save a named profile for a job or activity, and link it to a job so it loads automatically. To link it, pick the profile under **Saved profiles**, pick any job under **Load this profile when I change to** and click **Link**. **Linked:** lists the jobs the picked profile loads on, **Unlink** takes the job in the list off it, and **Unlink all jobs** clears every link. A linked profile loads when you change to its job. It also loads when you log in after changing job while Vantage wasn't running. It doesn't load when it's already the active profile, so what you saved since it loaded stays, and so do locks and moves. Profiles change presentation and rules while the tracker keeps running. Party-member selections stay personal when you load a profile. Save as new refuses to replace a profile. Overwrite and delete use a separate confirmation. Rename updates this character's job links. **Undo the last profile change** undoes the latest file change during the current addon session, as long as that profile hasn't changed somewhere else since. It keeps unrelated profile edits. The list and active-profile summary refresh four times per second while this page is open. Local edits and profile actions update the summary right away. Saving, loading, renaming, overwriting, deleting and recovery still check the current file, including their conflict guards.

To give a friend a saved profile, pick it in the list and click **Export to clipboard**. Vantage copies it as a whole profile export without loading it. Your screen doesn't change and nothing goes into Undo. Send it in a message, or click **Export to a file** to keep it as a `.txt` file named after the profile in `config/addons/vantage/shared/`. Vantage makes that folder when it needs it. It keeps only letters, digits, spaces, hyphens and underscores in the file name, and it leaves your Windows name and the names of the characters on this PC out of it. It never writes over a file that's already there. A second save of Raid becomes `Raid 2.txt`. A whole profile is long, so Discord may turn one into a file named `message.txt`. It opens like any other file.

To use one a friend sent, copy it and click **Import from clipboard**. Or put their file in your `shared` folder, click **Import from a file** and pick it. Vantage fills in the name after **Save it as**. It's "Imported" for one from the clipboard. For a file, it's the file's name without `.txt`, cut to 40 characters. If that name is taken, Vantage adds " 2" and so on. Type another name if you like. If a profile of yours already has that name, Vantage asks for another, since this never replaces a profile. **Save as a new profile** saves it without loading it and picks it in the list, so **Load** is one click. It keeps your own locks, party members, watch list, job links, diagnostics settings and chat colors. When its displays were placed on a screen of another size, Vantage says so and ticks **Keep my own display positions**. That keeps where your displays sit and their sizes. Untick it to take the profile's. **Clear** drops it and saves nothing. You can also bring in a file or clipboard export of any kind with **Import and add** or **Import and replace** (see Import and export). Vantage never deletes your files in the shared folder.

**Start over**, at the end of the page, has two buttons. **Put every display back where it started** sends every display to its first spot on this screen, following nothing and locked. ## If something looks wrong

Turn on **Show samples** to tell a hidden or filtered panel from missing game data. Check that the panel is ticked on the main page, then look at its **Filters** tab and its **When to show** tab. A blank caster or an effect with no countdown is normal when Vantage didn't observe that information. If it's still wrong, `/vg report` saves what Vantage found to `reports/latest.json` in the settings folder.

Settings are JSON, never executable Lua. Vantage keeps invalid existing JSON instead of writing over it, and reports it by file name. An empty file counts as no settings, so Vantage starts from the defaults and saves over it. Keep a copy before you repair a damaged settings file, and save it as UTF-8. A byte order mark is fine, but Vantage can't read UTF-16, which Windows PowerShell 5.1 writes by default. Vantage reports disk or audio failures locally. A fresh reload starts with a quiet baseline. It can't recover old enemy applications that the client never sent to this session.

## After a game update

When it loads, Vantage uses short byte patterns to find a few things in the game client. Following the chat log uses the chat window and menu scale. The visibility options use the event, interface and map flags. The buffs beside the party list use the game's party list rows and the Treasure Pool window. Your own countdowns use the game clock, and overhead icons use the point the game hangs each name from. Item recasts use Ashita's item data library, which looks for patterns of its own. Right after a game update, one of them may not be found yet. Then only that part stops. Depending on which part it is, your own buffs show without a countdown, item recasts turn off, following the chat log is unavailable, the party list buffs aren't drawn, overhead icons go back to their guessed heights, or the visibility options stop working. Everything else keeps working. Chat says so once when the game clock or those flags are missing, and `/vg report` says which part is missing. The Recasts panel also says when item recasts are off. There's nothing to turn off. A Vantage or Ashita update that knows the new client brings it back.
